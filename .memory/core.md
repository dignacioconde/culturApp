# Core Memory

Fallback para tareas sin una ruta específica. El índice operativo único está en [MEMORY.md](MEMORY.md).

- Leer el índice y cargar solo los destinos relevantes.
- Guardar preferencias, decisiones y gotchas reutilizables; nunca sesiones, logs, ramas, commits, secretos ni snapshots.
- Enlazar la fuente canónica en vez de duplicarla.
- La memoria nunca prevalece sobre instrucciones actuales, código, tests o documentación canónica.
- Al cerrar, guardar solo aprendizaje durable o declarar `Memoria: no aplica`.
