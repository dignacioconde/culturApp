# CACH-0106 — Orquestación multi-modelo con cerebros y obreros baratos

## Objetivo

Separar planificación/revisión (Claude Code y Codex vía sus CLIs oficiales) de implementación acotada (modelos baratos vía API propia u Ollama), con contexto compartido en ficheros del repo.

## Alcance

Incluido:

- Capa de contexto: `docs/handoff.md`, `docs/decisions.md`, `docs/tasks/`, `docs/orchestration.md`, ampliación de `AGENTS.md` y `CLAUDE.md`.
- MCP `codex-bridge` (wrapper de `codex exec`/`codex review`) y MCP `cheap-worker` (delegación en worktrees con `opencode run`).
- Comandos `.claude/commands/`, subagente `task-splitter`, `scripts/profiles.sh`.
- Demo `examples/demo/` y documentación `tools/README.md`.

Fuera de alcance:

- Código funcional de la app, Supabase o producción.
- Uso de credenciales de suscripción fuera de `claude` y `codex`.

## Criterios de aceptacion

- [x] AC1: Un agente nuevo leyendo `AGENTS.md` y `docs/handoff.md` sabe el siguiente paso.
- [x] AC2: `.mcp.json` registra `codex` y `cheap-worker`; ambos responden a un smoke test MCP.
- [x] AC3: `delegate_task` trabaja en worktree propio, nunca hace merge, reintenta N veces y aplica fallback.
- [x] AC4: Ningún secreto versionado; `.env.example` documenta las variables.
- [x] AC5: La demo `examples/demo/` recorre plan → delegate → review → handoff.

## Validacion
